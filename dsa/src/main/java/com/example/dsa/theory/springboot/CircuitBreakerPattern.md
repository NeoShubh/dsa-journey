Circuit Breaker is a design pattern that prevents a service from repeatedly calling another service that is failing. Initially, the circuit remains in the Closed state and requests are allowed. If the number of failures exceeds a configured threshold, the circuit opens and immediately returns a fallback response instead of calling the failing service. After a configured wait time, it moves to the Half-Open state, where it allows only a few requests to check whether the service has recovered. If those requests succeed, the circuit closes again; otherwise, it reopens.
